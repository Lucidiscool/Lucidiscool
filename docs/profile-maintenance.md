# Profile maintenance

This repository powers the `Lucidiscool` GitHub profile README.

The pinned projects table and `assets/contributions.svg` are generated by the Refresh profile workflow. Edit the normal README sections by hand, but leave the generated markers in place:

- `<!-- PINNED-PROJECTS:START -->`
- `<!-- PINNED-PROJECTS:END -->`

To refresh the generated content early, run the Refresh profile workflow from the repository Actions tab.
